# Hardware Guide

THE ARK targets ordinary x86-64 hardware first.

| Profile | Suggested RAM | Media |
|---|---:|---:|
| NANO | 8–16 GB | 64+ GB |
| FAMILY | 16 GB min / 32 GB preferred | 256+ GB SSD |
| NOMAD | 32 GB floor / 64 GB preferred | 1 TB SSD/NVMe |

GPU acceleration is optional; CPU operation remains the portability baseline.

Do not assume every Wi-Fi chipset supports Linux AP mode. Ethernet is the reliable fallback.

For long-lived nodes use reputable storage, maintain independent replicas, verify hashes periodically and refresh aging media.
