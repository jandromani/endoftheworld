# Capability Catalog

`manifests/capabilities.yml` is THE ARK's scouting/catalog plane.

Tracked examples include Project NOMAD, Kiwix, llama.cpp, Bitchat, Meshtastic, Reticulum, Organic Maps, SatDump, Bitcoin Core, Syncthing, Forgejo, Verdaccio, Bandersnatch, Qdrant, code-server, CyberChef, PlatformIO and Arduino CLI.

Catalog presence does **not** mean downloaded, approved, running or included in every profile.

Profiles are the promoted, budgeted product definition.

A candidate should enter a profile only after its purpose, upstream source, budget, integrity strategy and runtime/archival role are understood.
